# 달빛 가사 · 공개 데모

일본어 원문, 후리가나, 한국어 번역과 어휘를 함께 읽는 Flutter 앱의 소스 전용 데모입니다. 원본 앱의 테마, 문서 로딩, 아오조라 형식 후리가나 표시와 어휘 색인을 바탕으로 공개용 화면을 구성했습니다.

`demo/`의 두 문서와 여섯 문장은 이 데모를 위해 새로 작성한 일상 일본어 산문입니다. 번역과 어휘 설명도 함께 작성했으며, 기존 노래 가사를 예제로 사용하지 않습니다.

## 포함 기능

- 문서 선택, 문장 읽기, 후리가나와 번역 표시 전환
- 일본어, 읽기, 한국어 검색과 문장별 어휘 펼치기
- 문서별 어휘 색인, 등장 횟수, 북마크와 북마크 필터
- 단어 뜻 퀴즈, 정답 피드백과 결과 점수
- 표시 설정과 북마크의 기기 내 저장
- 앱 안에서 의존성 라이선스 확인

공개 화면은 읽기·어휘·퀴즈의 핵심 흐름으로 줄였습니다. 원본의 세부 레이아웃, 퀴즈 진행·이력 저장, 오디오 재생과 문장 동기화는 포함하지 않습니다. 퀴즈는 탭이나 문서를 바꾸면 처음부터 시작합니다.

## 실행

Dart 3.11 이상을 포함한 Flutter SDK와 Android SDK, Android 기기 또는 에뮬레이터를 준비합니다. Android 빌드에는 [JDK 17 이상](https://developer.android.com/build/jdks)이 필요합니다. 검증 환경은 Flutter 3.41.0 / Dart 3.11.0입니다.

저장소를 받은 뒤 `pubspec.yaml`이 있는 최상위 디렉터리에서 실행합니다.

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

Android 프로젝트 파일만 제공합니다. 처음 Android 빌드를 실행하면 Flutter 도구가 Gradle 실행 스크립트와 래퍼 JAR을 SDK 캐시에서 준비하고 로컬 SDK 경로를 생성합니다. 이 파일과 경로는 저장소에 포함하지 않습니다. SDK·의존성의 최초 설치에는 네트워크 연결이 필요할 수 있습니다.

앱 ID는 `app.shinbi.tsuki_lyrics.demo`입니다. 원본 앱과 별개로 설치됩니다. 배포용 서명 설정과 서명 키는 포함하지 않습니다. 실행 예시는 개발용이며 스토어 출시 절차는 다루지 않습니다.

## 예문 구조

각 JSON은 `metadata`와 `sentences`를 가집니다. 문장에는 `id`, `original`, `ruby`, `translation`, `vocabulary`를 넣습니다. 후리가나는 `｜漢字《かんじ》` 형식으로 표시합니다. 전체 필드와 자료형은 [아침 준비 예문](demo/morning.json)을 참고하세요.

새 문서는 `demo/`에 `.json` 파일로 저장하면 자동으로 목록에 등록됩니다. 파일 이름은 서로 달라야 하고, 문장 `id`도 문서 안에서 중복되지 않게 지정합니다. 파일 추가 후에는 실행 중인 앱을 종료하고 `flutter run`으로 다시 빌드·실행하세요.

## 공개 범위

기존 `lyrics/`, 이미지·앨범 아트·음원, 외부에서 얻은 가사·번역·단어 데이터, 원본 테스트의 노래 예문, 다운로드 및 YouTube 연동 코드를 포함하지 않습니다. 달 아이콘은 간단한 벡터 도형으로 작성했습니다.

대화·결정 기록, 개인 설정, SDK 절대 경로, 비밀정보, 서명 파일, 빌드 결과물, 기존 Git 이력도 공개본에 포함하지 않습니다. 실제 곡이나 외부 자료는 사용자가 별도로 준비해야 하며, 그 자료의 이용·배포 조건은 각각 확인해야 합니다.

직접 의존성은 Flutter와 `shared_preferences`이며, 테스트와 정적 분석에는 `flutter_test`와 `flutter_lints`를 사용합니다. 이용 범위는 [RIGHTS.md](RIGHTS.md), 제3자 구성요소의 고지와 라이선스는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 확인하세요.
